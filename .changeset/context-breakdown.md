Every desk now shows how full its session's context is: the monitor gets messier as the context fills, from a tidy desktop to a pile of windows, sticky notes and a warning box. Click a monitor or a desk's name to see the context broken down (system prompt, tools, MCP tools, memory files, skills, your messages, replies, tool calls and results, free space). The breakdown's "watch replay" opens the session's replay, which a desk's name used to open.
