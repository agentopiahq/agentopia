Claude Code cloud sessions can now take a desk in your office. `agentopia relay pair` makes a token; give it to the cloud environment as `AGENTOPIA_RELAY`, allow `www.agentopia.town` in its network settings, and the repository's hooks record the session there and relay it through agentopia.town to your office. Everything is sealed with the token before it leaves the cloud machine, so agentopia.town only ever holds ciphertext. `agentopia relay hooks` and `agentopia relay stage` set up repositories other than agentopia's own, and `agentopia relay off` unpairs.
