# @agentopia/cli

`@agentopia/cli` was an alias for [`agentopiahq`](https://www.npmjs.com/package/agentopiahq):
the same `agentopia` command, released at the same version. It is no longer published; 0.4.0
was its last release. Install `agentopiahq` instead:

```sh
npm i -g agentopiahq
```

An install of `@agentopia/cli` 0.4.0 keeps itself current anyway, since the CLI's
self-update always downloads `agentopiahq`.

The package stays here, private, so the name can be published again if it is ever wanted.
